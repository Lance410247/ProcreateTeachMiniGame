## Procreate教學小遊戲
此遊戲是由Lance開發，為了上課教學所製作的遊戲。基本功能都是為了我方便講課所製作，可能會有一些BUG。
![image](https://github.com/Lance410247/ProcreateTeachMiniGame/blob/main/MDimage/Tilie.png)

----
### 使用方法
點擊Release下載，解壓縮後執行Procreate教學小遊戲2026.exe後即可遊玩。
